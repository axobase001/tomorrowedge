# TomorrowEdge Product Guide

TomorrowEdge is a full-access coding workflow cockpit for heterogeneous coding
agents.

## Core Thesis

The future of AI coding is not one model. It is role-routed engineering
workflows where different models and external coding agents are assigned to the
work they are best suited for.

## Product Pillars

- Full-access cockpit: autonomous patch, shell, repair, and review loops with
  visible trace.
- Heterogeneous model teams: planner, explorer, coder, reviewer, judge, runner,
  repairer, summarizer, and optional core roles.
- Capability stitching: one model can perceive, another can implement.
- External agent bridge: Codex and Claude Code can be role-bound nodes rather
  than replacements for TomorrowEdge.
- Context projection: full artifacts are preserved, compact evidence is shown
  to models.
- Budget discipline: strong agents are scarce decision resources.

## Product Boundary

TomorrowEdge should not become a general personal-agent runtime. It should stay
focused on engineering delivery: patch, test, review, judge, trace, and cost.
