# Code of Conduct

TomorrowEdge follows a simple contributor standard: be respectful, concrete,
and evidence-oriented.

Expected behavior:

- Treat contributors and users with respect.
- Critique code, docs, and product decisions without personal attacks.
- Keep security-sensitive reports private until they are triaged.
- Avoid posting API keys, tokens, private traces, or user data in public issues.

Unacceptable behavior:

- Harassment, threats, or discriminatory language.
- Publishing another person's private information.
- Deliberately submitting malicious code, secret exfiltration, or destructive
  workflow changes.

Maintainers may edit, hide, close, or remove content that violates these rules.
