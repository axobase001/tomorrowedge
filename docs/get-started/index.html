Get started

Install locally. Run offline first.

Default demos and tests use mock and fixture providers, so you can validate the cockpit before adding cloud keys.

Quickstart

From clone to cockpit.

Use the offline path first, then configure providers only when the local workflow is healthy.

node --version # requires Node >=20.19.0

npm install

npm test

npm run dev -- doctor

npm run dev -- run "fix failing test" --headless --fixture-mode --approve-patch --approve-shell

npm run dev -- tui
