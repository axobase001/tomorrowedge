# Clean-Room Note

TomorrowEdge is independently designed as a clean-room implementation.

This repository does not copy, reference, reproduce, or reverse-engineer leaked Claude Code CLI source code, leaked prompts, hidden schemas, proprietary tool protocols, internal names, or non-public workflows.

Allowed inputs for this project are public concepts, public APIs, public open-source tooling, and independently designed interfaces for model routing, agent orchestration, permissions, patch handling, and TUI supervision.

If a contribution depends on leaked or proprietary material, it must not be merged.
