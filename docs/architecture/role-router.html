Role router

Different agents need different models.

The router maps roles to provider/model choices so planning, exploration, coding, review, judging, and repair can use the right capability and price profile.

Planner

High-value judgment

Reserve stronger models for decomposition, tradeoffs, and final decisions.

Coder

Execution lanes

Route routine implementation and repair to models optimized for throughput and cost.

Reviewer

Independent checks

Use review and judge roles to prevent a single model from marking its own work as done.
