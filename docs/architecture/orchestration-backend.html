Orchestration backend

Execution emits events.

The native backend runs TomorrowEdge workflows now. External backends can integrate later by producing the same event stream instead of taking over the cockpit.

Contract

Backend execution, cockpit ownership.

The backend may execute, but access modes, authorization, routing, trace, replay, and export remain TomorrowEdge product surfaces.
