# Four-Zone Quiet Cockpit Tokens

```text
background     #F6FAFC
surface        #FFFFFF
alt-surface    #EEF5F8
border         #D7E4EA
border-strong  #B8CBD5
text           #17212B
muted          #6B7A88
primary-blue   #6FAFD2
deep-blue      #2F6F92
success        #2F9D68
warning        #B7791F
danger         #C94A4A
```

Rules:

- Use blue for active workflow focus and primary actions.
- Use green only for passed/done states.
- Use amber only for waiting/approval-needed states.
- Use red only for failed/rejected states.
- Keep radius at `6px` or less for panels and controls.
- Keep composer height secondary to the workflow workspace.
